How this demo works

DeepBell monitors its own server process: the CPU and memory on this page belong to the app you are looking at, sampled every 2 seconds.{% if public_demo %} This is a shared instance: everyone visiting sees the same telemetry and the same faults.{% endif %}

  1. 1
    Watch

    The watchdog learns a baseline and flags samples that move well away from it.

  2. 2
    Inject a fault

    In the Chaos Lab, spike the CPU, leak memory or corrupt the database.

  3. 3
    Read the report

    Each incident gets a report{% if api_key_configured %} written by Gemini{% else %} from a built-in template{% endif %}, shown on this page.

  4. 4
    Roll back

    The Time Machine restores the database from a snapshot.
